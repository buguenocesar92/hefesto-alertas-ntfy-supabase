# Servicio Hefesto
Oferta: implementación y capacitación inicial + mensualidad por operación, monitoreo, respaldo, actualizaciones y soporte. Cobrar según sistemas integrados, volumen, retención y horario de atención. No se estiman márgenes sin costos reales.

Alcance inicial: panel web nativo ntfy, cuentas y ACL, avisos HTTP, adjuntos temporales y guía móvil. Paquete de integración opcional por sistema: respaldo, despliegue, inventario bajo o incidentes. ntfy no detecta eventos por sí mismo: cada sistema debe emitirlos.

La imagen se conserva sin cambios. Upstream publica ntfy bajo Apache2.0/GPL2.0; revisar licencia y avisos al distribuir modificaciones. No se incluye una app móvil propia ni white-label. No hay integración con WhatsApp, Flow o correo habilitada.

Propuesta de lanzamiento: instalar una instancia piloto, conectar un respaldo y un monitor, comprobar entrega y recuperación durante una semana y acordar SLA antes de ofrecer servicio gestionado.
